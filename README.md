# Sayohat.uz

O‘zbekiston bo‘ylab sayohat uchun o‘zbek tilidagi statik, ko‘p sahifali veb-sayt.

## Ishga tushirish

index.html faylini brauzerda oching. Hech qanday kutubxona yoki server talab qilinmaydi.

## Sahifalar

- index.html — bosh sahifa, avtomatik hero slayder, tavsiyalar va sharh.
- manzillar.html — 8 manzil va ishlaydigan turkum filtri.
- marshrutlar.html — to‘rtta batafsil sayohat dasturi.
- galereya.html — tashqi manbadagi real suratlar galereyasi.
- aloqa.html — yuborilganda tasdiq ko‘rsatadigan aloqa formasi va FAQ.

Suratlar Unsplash CDN orqali yuklanadi; internet aloqasi kerak.
